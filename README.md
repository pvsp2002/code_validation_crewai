# 🧠 CrewAI Code Validation System

A multi-agent **backend-first AI system** built using **CrewAI**, with a lightweight **Streamlit frontend** for displaying final validated artifacts.

This project automatically:
- Generates Python code from user requirements
- Reviews and corrects the code
- Creates comprehensive test cases
- Executes tests
- Produces a final validation score

The frontend **does not control logic** — it only displays results generated by the backend pipeline.

---

## 🚀 Features

- ✅ Multi-agent architecture (Developer, Error Handler, Tester, Reviewer)
- ✅ Fully automated validation pipeline
- ✅ Robust test coverage (normal, edge, failure cases)
- ✅ Final approval score (0–100%)
- ✅ Clean frontend output (no agent logs)
- ✅ Execution time measurement
- ✅ Modular, extensible design

---

## 🧩 Architecture Overview

User Input
↓
Developer Agent → generates initial code
↓
Error Handler → fixes issues and improves code
↓
Use Case Designer → creates test scenarios
↓
Testing Engineer → executes tests
↓
Code Reviewer → produces validation score
↓
Frontend → displays final artifacts only

### 🔑 Design Principle
> **All intelligence lives in the backend.  
Frontend is only a renderer.**

## ⚙️ Requirements

- Python **3.10+**
- CrewAI
- Streamlit
- LangChain
- python-dotenv

Install dependencies:

```powershell
pip install -r requirements.txt
```

## 🔐 Environment Setup

Create a .env file:

```.env
OPENAI_API_KEY=your_api_key_here
CREWAI_DISABLE_TELEMETRY=true
```


Telemetry is disabled to ensure compatibility with Streamlit.

## ▶️ Running the Application
Start the frontend

``` powershell
streamlit run frontend_time.py
```

``` powershell
http://localhost:8501
will be opened
```

## 🖥️ Frontend Output

The UI displays only final validated artifacts:

🧑‍💻 Generated Python code

✏️ Corrected / improved code

🧪 Generated test cases

🧾 Test execution results

📊 Final validation score

⏱ Total backend execution time

No agent logs, no telemetry, no internal reasoning.

## ⏱ Execution Time Measurement

The total backend execution time is measured using:

``` 
time.perf_counter()
```

This includes:

- All agents

- All LLM calls

- All test executions displayed clearly in the frontend.
